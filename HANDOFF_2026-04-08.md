## What Changed

### GUI

- Reduced minimum main window height in `assistant_gui/main.py` to allow compact layouts.
- Added smaller display presets in `assistant_gui/pages/settings_page.py`.
  - `초소형 (1280 x 420)`
  - `와이드 낮음 (1600 x 420)`
  - `와이드 컴팩트 (1600 x 480)`
  - existing presets remain
- Fixed settings-page preset syncing so compact heights are recognized instead of falling back to older `1600 x 600` logic.
- Default saved restore height is now `560` instead of the stale `600`.
- Lowered map/weather related minimum heights earlier so the GUI can shrink vertically much more than before.

### Command / Orchestrator / Audio Flow

- Unified command topic flow around `/assistant/command_text`.
- Added robot/PC voice input runtime toggles and speaker volume control.
- Added overlay execution for TTS-only status commands while a movement mission is active.
- Added cancel-command handling for active missions.
- Added local runtime data handling for schedules, alarms, and medication queries/additions.
- Added named-place config support and GUI editing for named places.
- Added person greeting runtime toggle and overlay pause/resume around OCR and gesture flows.

### Robot / Navigation / Recognition

- Added named place catalog and action-based navigation bridge wiring.
- Added scheduler support for packaged scheduled missions and runtime data driven missions.
- Added registered-person recognition node backed by `plus/face_db.pkl`.
- Fixed `person_recognition_node.py` logger misuse that previously crashed with:
  - `TypeError: RcutilsLogger.warn() takes 2 positional arguments but 3 were given`
- Cleaned shutdown handling in audio nodes and person recognition node.

### Bringup / Deployment

- Added distributed/production launch files under `assistant_bringup/launch`.
- Local builds succeeded for changed packages.
- Remote builds succeeded when using direct package base paths.
